What Is This & Why Does It Matter

🔓

The Problem

Impact Cloud+ content has always required a locked Android APK to play on physical signs. That ties every deployment to Android hardware — which we don't control on competitor installs.

⚙️

What We Built

A standalone desktop player that reads the same .vsn playlist files, connects to Impact Cloud+, and renders content with full visual parity — no Android required. Video, images, text, clocks, weather, countdown timers, and multi-item playlists all render correctly.

🎯

The Opportunity

Existing competitor hardware running Windows in the field can be converted to run our player with a single install command. No hardware swap needed.

Features

Built-In Settings & Configuration

The player includes a full settings panel accessible at any time via F12. Field techs can adjust resolution, fullscreen mode, Impact Cloud+ credentials, polling interval, and more — all without touching a config file manually.

Display Settings

Resolution, fullscreen toggle, fit mode, target FPS, brightness

Impact Cloud+ Sync

Server URL, Terminal ID, Terminal Secret, auto-sync on/off, poll interval

Playback

Loop program, info HUD overlay, timezone and locale for clock and countdown items

Supported Content Types

Video (MP4/H.264), images (PNG/GIF with transparency), scrolling & static text, digital & analog clocks, countdown timers, weather, multi-item playlists

Compatibility

Where Can I Deploy It

Platform Status Notes
Windows 10 / 11 Supported Runs natively as a self-contained .exe. Most competitor field hardware runs Windows 10 — this is the main conversion target.
Samsung PrismView Supported Dedicated signage hardware running Windows. The installer and auto-updater include a built-in System Matrix watchdog — if System Matrix crashes, the player restarts it automatically.
OrangePi / Linux SBC Supported Low-cost single-board computers running Debian/Ubuntu. One-line Linux installer included. Ideal for new low-cost deployments.
Mini PC / Intel NUC Supported Small form factor Windows/Linux boxes. Ideal for permanent installs. Intel Quick Sync hardware video decode is automatically used when available, keeping CPU usage minimal.
Raspberry Pi 4 / 5 High Value ~$70 all-in. Runs Linux, drives HDMI output, fully supported via the Linux installer. Good option for new low-budget deployments.
Key Point Because this is a standard compiled executable rather than a locked APK, it runs on virtually any modern computing platform. Content distribution stays exactly the same — Impact Cloud+, device terminals, and playlist files are unchanged. Only the playback hardware changes.
Deployment

How I'm Deploying It

📦

Packaged as a Windows Executable

The player is compiled into a single .exe file using PyInstaller. The target machine needs nothing pre-installed — no Python, no dependencies, no technical setup. Just run the installer and it handles everything automatically.

Live
🐙

Hosted on GitHub

The source code and compiled releases live in a public GitHub repository. When a new version tag is pushed, GitHub Actions automatically builds the updated .exe and publishes it as a GitHub Release — making it immediately available to all deployed units via auto-update.

Field Install Process
1

Open Command Prompt as Administrator on the Target Machine

Click Start, type cmd, right-click "Command Prompt", and select Run as administrator. Admin rights are required — the installer will exit immediately if not elevated.

2

Run the Installer — One Line

The field tech pastes a single command into the Admin Command Prompt. This pulls the installer directly from GitHub and runs it automatically. No Python or other software needs to be pre-installed.

curl -fsSL https://raw.githubusercontent.com/Sacton86/Cloud-Desktop-Edition/main/full-install.bat -o %TEMP%\full-install.bat && %TEMP%\full-install.bat
3

Enter Device Credentials & Display Settings

The installer prompts for: Device type (Windows / Samsung PrismView), Terminal ID, Terminal Secret, Impact Cloud+ server URL (defaults to access.impactledsigns.com), and display resolution with fullscreen preference. Everything else is automatic.

4

Done — Player Launches & Auto-Starts

The installer downloads the latest ImpactLED-Cloud-Player.exe from GitHub Releases, writes the config file, registers two Windows startup tasks (player launches at logon, updater checks for new versions 5 minutes after every boot), and launches immediately. Total time: under 60 seconds.

Deployment is Live The GitHub repository, installer, and auto-update system are all active. The command above is the current production install command. Releases are available at github.com/Sacton86/Cloud-Desktop-Edition/releases.
Ongoing Maintenance

Updating Deployed Units

🔄

Content Updates

Nothing changes here. Content is pushed through Impact Cloud+ exactly as it is today. The player checks in automatically every 30 seconds and pulls new playlists.

No Change Required
⬆️

Software Updates

When a new version is released, deployed units update automatically. The updater runs 5 minutes after every boot, checks GitHub for a new release, and installs it silently without touching device credentials or config. Samsung PrismView devices automatically have their System Matrix watchdog rewritten after every update.

Fully Automatic
🏷️

Releasing a New Version

Push changes to GitHub, then push a version tag (e.g. v1.0.29). GitHub Actions builds the exe automatically and publishes the release. All deployed units pick it up on their next reboot.

Done
Field Reference

Useful Commands for Technicians

Check Installed Version

Run in any Command Prompt on the device:

type C:\ImpactLED\CloudPlayer\version.txt

Force Immediate Update Check

Run as Administrator to update without rebooting:

C:\ImpactLED\CloudPlayer\updater.bat

Uninstall

Run as Administrator to remove everything — player, startup tasks, and install folder:

schtasks /end /tn "ImpactLED Cloud+ Desktop Player" >nul 2>&1 && schtasks /end /tn "ImpactLED Cloud+ Updater" >nul 2>&1 && schtasks /delete /tn "ImpactLED Cloud+ Desktop Player" /f && schtasks /delete /tn "ImpactLED Cloud+ Updater" /f && taskkill /f /im "ImpactLED-Cloud-Player.exe" >nul 2>&1 && rmdir /s /q "C:\ImpactLED"

Manage Startup Tasks

Open Windows Task Scheduler and look for:

  • ImpactLED Cloud+ Desktop Player — launches at logon
  • ImpactLED Cloud+ Updater — runs 5 min after every boot
